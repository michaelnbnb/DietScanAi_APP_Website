Dasar Privasi

Terakhir Dikemaskini: 18 Mei 2025

Diet Scan AI ("kami," "milik kami," atau "kita") komited untuk melindungi privasi anda. Dasar Privasi ini menerangkan amalan data kami untuk aplikasi analisis pemakanan dan pengiraan kalori kami.

Amalan Pengendalian Data

Simpanan Tempatan Sahaja

Semua data yang anda masukkan dalam Diet Scan AI, termasuk metrik kesihatan (berat, tinggi, umur), matlamat kecergasan, dan log makanan, disimpan secara eksklusif di peranti anda.

Kami tidak menyelenggara akaun pengguna atau menyimpan data peribadi anda di mana-mana pelayan.

Anda mengekalkan kawalan sepenuhnya ke atas maklumat anda pada setiap masa.

Penggunaan API Analisis Makanan

Apabila anda menggunakan aplikasi kami untuk menganalisis item makanan:

  • Penerangan/nama item makanan dihantar ke API analisis pemakanan pihak ketiga kami
  • Tiada maklumat pengenalan peribadi dihantar bersama permintaan analisis makanan ini
  • API mengembalikan maklumat pemakanan yang dipaparkan dalam aplikasi dan disimpan hanya pada peranti anda
  • Perkhidmatan analisis makanan mungkin menyimpan log pertanyaan makanan tanpa nama untuk meningkatkan ketepatan perkhidmatan mereka
  • Semua komunikasi dengan API disulitkan menggunakan protokol standard industri

Pengisytiharan Wajib App Store

Sebagai mematuhi keperluan Label Pemakanan Privasi Apple, kami mengisytiharkan:

  • Data Tidak Dikumpul: Kami tidak mengumpul sebarang maklumat peribadi, maklumat hubungan, pengecam, atau data kesihatan dari peranti anda
  • Data Digunakan untuk Fungsi Aplikasi Sahaja: Data makanan yang diserahkan kepada API kami digunakan semata-mata untuk tujuan analisis pemakanan dan tidak dikaitkan dengan identiti anda
  • Tiada Penjejakan: Kami tidak menjejaki anda merentasi aplikasi atau tapak web yang dimiliki oleh syarikat lain

Analitis Apple

  • Statistik penggunaan tanpa nama mungkin dikumpul oleh Apple melalui alat analitis standard mereka
  • Data ini dianonimkan dan diagregatkan oleh Apple dan membantu kami memahami prestasi aplikasi
  • Anda boleh menarik diri daripada pengumpulan data ini melalui tetapan peranti anda pada bila-bila masa

Hak dan Kawalan Anda

  • Memandangkan semua data anda disimpan secara tempatan pada peranti anda, anda boleh memadam semua data dengan hanya memadamkan aplikasi
  • Tiada pemulihan data yang mungkin selepas aplikasi dipadamkan, kerana kami tidak menyimpan sebarang sandaran di pelayan

Perubahan kepada Dasar Ini

Kami mungkin mengemas kini Dasar Privasi ini dari semasa ke semasa. Kami akan memberitahu anda tentang sebarang perubahan dengan menyiarkan dasar baharu di halaman ini dan mengemas kini tarikh "Terakhir Dikemaskini".

Hubungi Kami

Jika anda mempunyai sebarang soalan mengenai Dasar Privasi ini, sila hubungi kami di support@dietscanai.app.
